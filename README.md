# KEEPERS for Pixels

AI 이미지가 자주 틀리는 곳(여섯 개 손가락, 꺾인 손목, 짝짝이 눈, 깨진 글자, 앞뒤가 안 맞는 장면)을 짚어 주는 판독기입니다. 판독 결과는 참고용입니다. 판독 결과를 보고 쓸 만한 한 장을 고르고(Pick), 편집해(Edit), 원하는 형식으로 내보내며(Export), 최종 1장에 든 AI 비용까지 알려 줍니다.

- 배포 주소: https://keepers-for-pixels.vercel.app
- 소스 저장소: https://github.com/S13ee/keepers-for-pixels
- 이전 프로젝트: [Keepers for AI](https://keepers-for-ai.vercel.app) — 중간 점검 1차 버전, 그대로 보존

## 흐름
첫 화면에서 **GO**는 AI 판독을 포함한 흐름, **이미지만 편집하기**는 판독 없이 올리기·고르기·편집·내보내기만 하는 흐름입니다.

1. **Upload** — 사용한 AI와 요금제를 고르고 이미지를 여러 장 올립니다. AI 이미지가 아니면 "일반 사진"으로 씁니다. 만들 때 쓴 프롬프트를 적으면 판독이 의도를 이해하는 데 씁니다.
   - **AI 판독**: Google Gemini가 손가락·손, 얼굴·눈, 몸·팔다리, 글자, 사물·배경, 장면 논리, 주제를 한 장씩 검수하고 문제 위치를 표시합니다. "내 API 키" 또는 "무료 판독"(사이트 제공, 하루 한도) 중에서 고릅니다.
   - 판독은 두 단계입니다: 그림 전체를 본 뒤, 손·얼굴이 의심되면 그 부분만 잘라 크게 키워 맞는지 확인합니다(새 의심은 만들지 않음).
   - AI가 확실하다고 본 오류는 빨간 배지에 이름까지(예: 손가락·손 오류), 확신하지 못한 곳은 이름 없이 노란 "확인 필요"와 번호 점선 네모로 위치만 표시합니다. 가능성이 낮은 것은 리포트에만 남깁니다.
   - 설계 이유: 시험해 보니 AI는 이상한 위치는 잘 짚지만 오류 이름은 자주 틀렸습니다. 그래서 확신이 없을 때는 이름 대신 위치를 보여 주도록 바꿨습니다. 판독 중에는 남은 예상 시간을 보여 줍니다.
2. **Pick** — 화질 낮음, 흐릿함, 어두움·밝음, 비슷함을 자동 점검하고 Keep / Skip을 고릅니다. 배지 색은 심각도입니다: 빨강 큰 문제, 노랑 확인 필요, 무색 참고 정보. 최종 1장당 비용이 실시간으로 바뀝니다.
3. **Edit** — 자르기(증명 3×4cm, 여권 3.5×4.5cm 포함), 회전·뒤집기, 밝기·대비·채도·색온도·그레인·선명도, 크기·dpi·화질, 목표 용량(예: 200KB 이하) 맞추기.
4. **Export** — JPG · PNG · WebP · GIF · TIFF · PSD · BMP · ICO · SVG · PDF로 내보내기 (AVIF는 브라우저가 지원할 때만), 전부 ZIP·한 PDF로 받기, 비용 계산 과정, 비용 줄이기, 다음 프롬프트 요청문 복사, 요약 TXT · 기록 CSV.

## 특징
- 자동 점검, 편집, 내보내기는 모두 브라우저 안에서 처리합니다. 이미지는 AI 판독을 켰을 때만 작게 줄인 사본이 Google(Gemini)로 전송되고, 탭을 닫으면 사라집니다.
- AI·요금제 선택과 이번 달 누적 기록만 브라우저(localStorage)에 저장합니다.
- 한 개의 HTML 파일로 만들었습니다. PDF·ZIP 만들기 도구(jsPDF, JSZip)는 필요할 때만 cdnjs에서 불러옵니다.

## AI 판독 서버 (api/judge.js)
- Vercel 서버 기능입니다. 무료 판독 요청을 받아 Gemini에 보내고 결과만 돌려줍니다.
- API 키는 코드에 없고, Vercel 프로젝트 설정의 환경 변수 `GEMINI_API_KEY`에만 둡니다.
- 이 사이트에서 온 요청만 받으며, 하루 한도(전체 `DAILY_LIMIT`=200, 한 사람 `IP_DAILY_LIMIT`=40)를 둡니다. 이미지 한 장은 전체 판독 1번에, 손·얼굴이 의심되면 확대 확인 1번이 더해져 최대 2번 셉니다.
- `GEMINI_MODEL` 환경 변수에 모델 이름을 넣으면 그 모델을 먼저 씁니다(예: 더 강한 Pro 모델 시험).
- 정확도를 위해 판독용 사본을 긴 변 1536px로 보내고, `gemini-flash-latest`를 먼저 씁니다(사용량이 차면 `gemini-flash-lite-latest`로). 생각 단계는 `GEMINI_THINKING`(기본 high)으로 바꿀 수 있습니다. temperature는 Gemini 3 공식 권장대로 기본값(1.0)을 씁니다.
- 판독 한 번의 최대 시간은 Vercel 기본값(무료 요금제 300초)을 따르고, 서버가 280초에 스스로 멈춰 안내합니다. 1분이 넘으면 화면에 "판독 정지" 안내가 뜹니다.
- "내 API 키"를 쓰면 키는 브라우저에서 Google로 바로 가고, 사이트 서버에 저장하지 않습니다.
